# Тише — стоматологический кабинет

Предварительный интерактивный макет для обсуждения с заказчиком.

## Просмотр

Откройте index.html или опубликованную страницу GitHub Pages. Внешних зависимостей нет.

## Демонстрационный режим

Запись и занятость условные. Сохраняются только дата и час в браузере. Имя и телефон никуда не отправляются и не сохраняются. Помощник отвечает по сценариям; нейросеть не подключена.

Рабочее название и сведения о кабинете требуют согласования.
